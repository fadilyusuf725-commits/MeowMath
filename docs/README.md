# Dokumen MeowMath

Folder ini ditata agar mudah dipakai dan tidak memuat versi dokumen yang saling bertumpuk.

## `siap-pakai`

Berisi dokumen Word dan PDF yang siap dicetak atau dibagikan.

Gunakan file bertanda **Revisi** sebagai paket final. File tanpa tanda tersebut dipertahankan hanya sebagai keluaran sebelumnya dan tidak digunakan untuk pengambilan data.

| Nomor | Dokumen | Pengguna |
| ---: | --- | --- |
| 01 | Pretest MeowMath Kelas VI — Paket A — Revisi | Murid, sebelum pembelajaran |
| 02 | Posttest MeowMath Kelas VI — Paket B — Revisi | Murid, setelah pembelajaran |
| 03 | Kunci dan Pedoman Penskoran — Revisi | Guru / peneliti |
| 04 | Instrumen Penelitian MeowMath — Revisi | Peneliti / pembimbing |
| 05 | Form Validasi Produk MeowMath — Revisi | Ahli media / produk |
| 06 | Form Validasi Materi MeowMath — Revisi | Ahli materi |
| 07 | RPM MeowMath Kelas VI — Tampak Tiga Arah — Revisi | Guru |

Untuk murid, cetak hanya nomor **01** atau **02**. Kunci tidak boleh dibagikan sebelum tes selesai.

## `sumber`

Berisi versi Markdown yang dapat diedit untuk tujuh dokumen siap pakai di atas.

Subfolder `sumber/template-acuan` menyimpan dua template validasi asli sebagai rujukan penyusunan. Gunakan formulir nomor **05** dan **06** untuk proses validasi MeowMath.

## Dokumen rujukan pembelajaran

| `unit-meowmath-kelas-vi.md` | Rencana pelaksanaan unit MeowMath kelas VI. |
